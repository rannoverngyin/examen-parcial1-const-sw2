-- Ejercicio aplicado de la sesion
Cada estudiante debe realizar el siguiente incremento:
	Crear o verificar un endpoint funcional de su proyecto, por ejemplo /productos o /config/info.
	Construir el JAR con Maven.
	Crear Dockerfile y .dockerignore.
	Construir la imagen Docker.
	Ejecutar la API en contenedor.
	Crear docker-compose.yml.
	Validar con curl y capturas.
	Registrar el cambio con Git.
